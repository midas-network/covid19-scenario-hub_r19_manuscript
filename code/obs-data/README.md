# Source Code

This folder stores code that is use in the Github Repository, including:

- Observed Data: code to extract and standardized target time series data.
    - `obs-data_utils.R`: function used to extract, process and standardized
       the observed data.
    - `obs-data.R`: script using the utils function to extract, process,
       standardized and write the observed data output file in the expected
       folder.
