# Code and files for the results associated with the summer and winter wave analysis
The .ipynb includes code for:
1. Pearson's correlation analysis (Main text Figure 3).
2. Mixed effects analysis (Main text Figure 3).
3. Supplemental mixed effects analysis where states were split into low, medium and high vaccination coverages (Suppl. Figures X (edit once finalized).

Necessary data files are in the data folder in this repo with the exception of hist_vacc_coverage_state.csv.
