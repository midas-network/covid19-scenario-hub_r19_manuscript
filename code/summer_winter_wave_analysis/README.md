# Code and files for the results associated with the summer and winter wave analysis
1. Analyze_outbreaks_hosp_final.ipynb includes code for the mixed effects analysis conducted to investigate vaccination scenario effects on the ensemble (Figure 4).
2. Analyze_outbreaks_hosp_SI_final.ipynb includes code for the correlation analysis conducted on the sizes of the winter and summer waves (Figure S22), SI mixed effects analysis for vaccination scenario effects per team split between locations with historically high summer or winter waves (Figure S23), and SI mixed effects analysis per team where states were further split into low, medium and high vaccination coverages (Figures S24-S26).

Necessary data files are in the data folder in this repo with the exception of hist_vacc_coverage_state.csv.
