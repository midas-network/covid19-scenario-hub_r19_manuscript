# COVID-19 Scenario Modeling Hub Round 19 Manuscript - Data

This folder contains the "processed" data for Round 19 of 
[COVID-19 Scenario Modeling Hub](https://covid19scenariomodelinghub.org/)
and auxiliary data

`model-processed`: contains the "processed" data
`data-locations`: contains the location name and ID used in the files

### Calculating Cumulative Samples, Quantiles and Ensembles

Additional targets are **only** calculated if not provided in the team-model
submission file and the associated round is expecting those targets (required
or optional).  

If the submissions files have `sample` output type specified via the 
`stochastic_run` and `run_grouping` columns, the `output_type_id` columns for 
this output type will be re-generated by concatenating the two columns together.

The cumulative samples will be calculated using the incident samples of the 
associated target and the quantiles are then calculated for all targets if
not provided by the team. 

To calculate the ensembles LOPs, the R package `CombineDistributions` is used 
(from GitHub: 
[eahowerton/CombineDistributions](https://github.com/eahowerton/CombineDistributions)
) with and without trimming (n=2).
To calculate the "ensemble", the R package `hubEnsemble` is used (from Github:
[Infectious-Disease-Modeling-Hubs/hubEnsembles](https://github.com/Infectious-Disease-Modeling-Hubs/hubEnsembles))/

#### Output:

The output data of this step is stored in a 
`model-processed` folder:

- One sub-folder per round and team, with the team-model name as name of the 
folder, in the SMH output file format, partitioned by `origin_date`, 
`team-model`, `target` and, `location`.

To load the data, please see the examples to load the "quantiles" data code 
below:
```r

repo_path <- "./"  # Path to the current repo
folder_path <- "model-processed/"

# Example 1
library(arrow)
schema <- arrow::schema(
    arrow::field("origin_date", arrow::string()),
    arrow::field("scenario_id", arrow::string()),
    arrow::field("location", arrow::string()),
    arrow::field("target", arrow::string()),
    arrow::field("horizon", double()),
    arrow::field("output_type", arrow::string()),
    arrow::field("output_type_id", double()),
    arrow::field("age_group", arrow::string()),
    arrow::field("model_id", arrow::string()),
    arrow::field("value", double()),
)

df <- arrow::open_dataset(paste0(repo_path, folder_path), schema = schema,
                          partitioning = c("origin_date", "model_id", 
			                   "target", "location")) |>
  dplyr::filter(output_type == "quantile", age_group == "0-130", 
                origin_date == "2025-04-27") |>
  dplyr::collect()

# Example 2 - using HubVerse tools
# hubData from: https://github.com/hubverse-org/hubData
# hubUtils from https://github.com/hubverse-org/hubUtils

# To install: 
# install.packages(c("hubData", "hubUtils"),
#                  repos = c("https://hubverse-org.r-universe.dev",
#                            "https://cloud.r-project.org"))

schema <- hubData::create_hub_schema(hubUtils::read_config(repo_path,
                                                           "tasks"))
df <- hubData::connect_model_output(paste0(repo_path, folder_path),
                                    schema = schema,
                                    partition_names = c("origin_date",
                                                        "model_id",
                                                        "target",
                                                        "location"),
                                    file_format = "parquet") |>
  dplyr::filter(output_type == "quantile", age_group == "0-130", 
                origin_date == "2025-04-27") |>
  dplyr::collect()
```
*Remarks*: As the round contains lot of data, it's highly recommended to 
filter before collecting the data.
